# Алгоритм детекції пластикових відходів на узбережжях і річках з використанням нейронних моделей

🇬🇧 [English version](README.en.md)

_(Plastic Waste Detection Algorithm for Coasts and Rivers Using Neural Models)_

## Опис проєкту

Проєкт є магістерською дисертацією з комп'ютерних наук. Його мета — підвищити точність автоматизованого виявлення дрібних пластикових відходів на аерофотознімках річок і морських узбереж за обмеженої кількості розмічених даних.

Основний метод — напівкероване навчання детектора **YOLO26** за схемою **Mean Teacher**: вчитель розмічає неанотовані кадри, учень навчається на розмічених даних і псевдомітках, а пороги впевненості задаються окремо для кожної категорії розміру об'єкта (Size-Stratified Ground Thresholding, SSGT). Експерименти виконано на наборах **FloW-img** (річки) та **UCWD** (узбережжя, UAV) за 10–100 % розмітки з контролем без псевдоміток.

## Академічні визначення

- **Мета роботи:** підвищення точності виявлення малорозмірних пластикових відходів на аерофотознімках водних об'єктів за обмеженої кількості анотованих даних шляхом напівкерованого навчання детектора.
- **Об'єкт дослідження:** процес автоматизованої детекції та моніторингу пластикових відходів у водоймах за допомогою систем комп'ютерного зору.
- **Предмет дослідження:** методи напівкерованого навчання (Mean Teacher, пороги за розміром об'єктів) для детекторів YOLO26 на малих об'єктах.

Основні результати дисертації (з анотації):

- Приріст $\text{mAP}$ відносно контролю за 10 % розмітки: **+0,020** на FloW-img і **+0,039** на UCWD.
- За повної розмітки приріст на FloW-img зменшується до **+0,003**.
- YOLO26m на FloW-img: $\text{mAP}$ **43,9 %**, $\text{mAP}_{50}$ **87,2 %**.
- Єдиним компонентом із помітним внеском виявився повільний вчитель (EMA 0,9996).
- SAHI не використовується в основних експериментах: у попередніх тестах він показав гірші результати, ніж нативний YOLO26.

## Конвеєр напівкерованого навчання (`code/ssod/`)

Конвеєр у [code/ssod/](code/ssod/) покращує YOLO26 на FloW-img, навчаючись також на неанотованих кадрах відео з річок.

| Модуль | Роль |
| --- | --- |
| [mean_teacher.py](code/ssod/mean_teacher.py) | `MeanTeacherTrainer`: розігрів, цикл напівкерованого навчання, EMA вчителя, оцінювання, чекпоінти, CLI. |
| [pseudo_labeling.py](code/ssod/pseudo_labeling.py) | Онлайн-розмітка на кожному кроці: 2-видове виведення вчителя, пороги за розміром, ваги боксів, журнал гістограм. |
| [dataset.py](code/ssod/dataset.py) | `SSODDatasetHandler` і `SSODSampler`: розмічені та неанотовані дані, окремі аугментації, порядок семплів в епосі. |
| [losses.py](code/ssod/losses.py) | `WeightedDetectionLoss`: втрата YOLO з вагами на бокс. |
| [metrics.py](code/ssod/metrics.py) | COCO-оцінювання (`pycocotools`): AP/AR, AP за розміром, пікова $F_1$. |
| [ablation.py](code/ssod/ablation.py) | Пакетні абляційні експерименти; результати в [ABLATION.md](code/ssod/ABLATION.md). |
| [export_results.py](code/ssod/export_results.py) | Експорт результатів у `paper/exp-results/`. |
| [recompute_coco.py](code/ssod/recompute_coco.py) | Перерахунок COCO-метрик із збережених `predictions.json`. |

### Процедура навчання

1. **Розігрів.** Навчання YOLO26 лише на розмічених даних; вагами ініціалізуються вчитель і учень.
2. **Початкові гістограми.** Вчитель розмічає рівномірну вибірку неанотованих кадрів; будуються гістограми оцінок за категоріями розміру.
3. **Базова лінія (епоха 0).** Оцінювання стартового вчителя на валідаційній вибірці.
4. **Кожна епоха SSL.** Нова рівномірна вибірка неанотованих кадрів; на кожному кроці: псевдомітки вчителя → крок оптимізації учня на GT + PL → оновлення EMA вчителя та гістограм. Наприкінці епохи — оцінювання вчителя; `best.pt` обирається за фітнесом Ultralytics: $0{,}1\cdot\text{mAP}_{50} + 0{,}9\cdot\text{mAP}_{50\text{-}95}$.

### Ключові параметри (типові значення коду)

| Параметр | Значення |
| --- | --- |
| Оптимізатор | AdamW, $lr_0 = 2\times10^{-4}$, $\beta = (0{,}937;\ 0{,}999)$, weight decay $5\times10^{-4}$ |
| Розклад швидкості | косинусний, до 1 % від $lr_0$ |
| EMA вчителя $\alpha$ | 0,9996 (за крок) |
| Неанотовані кадри на епоху | 4 800 (свіжа рівномірна вибірка з пулу ≈27 тис.) |
| Ваги псевдоміток | м'які, увімкнено |
| $\lambda_u$ | 1,0 без розгону |
| Хвіст лише з GT (`tail_ratio`) | 0 |
| Mosaic | лише для GT; вимкнено в останні 10 % епох |
| Довірливість кандидатів / NMS | 0,001 / 0,5 |
| Розмір входу / пакет | 640 / 16 |

Повний опис методу, рівнянь втрат і налаштувань — у тексті дисертації, розділ 2 (`paper/sections/section-2.typ`).
